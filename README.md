# publicQt

DB Dynamics（大博动力）桌面版 Qt 上位机的公开仓库。

本仓库用于发布与维护基于 Qt/C++ 开发的桌面上位机程序，包括串口通信、设备配置、数据监控与固件升级等功能。构建产物、版本说明与使用文档均在此公开。

## 说明

- 本仓库为**公开**仓库，仅包含可对外发布的桌面端代码与文档。
- 底层固件、内部工具及敏感配置不在本仓库范围内。
- 上位机使用静态编译，以便在无额外运行库依赖的环境下直接使用串口功能。

## 技术栈

- C++ / Qt
- 串口通信（QSerialPort）
- Windows 桌面平台
